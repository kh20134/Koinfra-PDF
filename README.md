# Koinfra PDF

Windows용 PDF 편집기(PyQt5)입니다. 여러 PDF를 합치고 페이지를 정리하며, 도장과 결재란을 넣어 저장할 수 있습니다.

## 주요 기능
- **페이지:** 병합, 추출, 삽입, 삭제, 회전, 드래그로 순서 변경, 썸네일 미리보기(칸을 넓히면 여러 열)
- **내보내기:** 썸네일을 클릭·Ctrl+클릭·Shift+클릭(Ctrl+A)으로 고른 뒤 오른쪽 클릭 → 내보내기 → PDF / 엑셀 / 한글 / 이미지
- **보안:** PDF 암호 설정과 해제
- **주석:** 사각형과 형광펜
- **도장:** 도장 이미지를 넣고, 오른쪽 클릭으로 설정과 저장
- **결재:** 결재란(담당/검토/승인 등)과 내 서명을 넣고, 오른쪽 클릭으로 설정과 저장
- **변환:** 열린 PDF(또는 다른 PDF)를 엑셀(.xlsx), 한글(.hwpx, 한컴 한글이 있으면 .hwp), 이미지(PNG/JPG)로 저장. 페이지 범위, 저장 위치, 이미지 해상도(DPI) 선택
- **인쇄**와 확대·축소
- **PDF 기본 앱 설정:** Windows 앱 선택 창 또는 설정 화면으로 연결하고, 설정이 끝나면 자동으로 확인

## 설치 (일반 사용자)
1. [Releases](../../releases)에서 `KoinfraPDF_Setup_1.4.3.exe`를 받아 실행합니다.
2. 마지막 화면의 **"PDF 기본 앱으로 설정"**을 체크한 채 마칩니다.
3. 뜨는 창에서 **Koinfra PDF 선택 → '항상'**을 클릭합니다.
   - 설정 화면이 열리면 **.pdf → Koinfra PDF → '기본값 설정'**을 클릭합니다.

> Windows 10/11은 기본 앱을 프로그램이 강제로 바꾸지 못하게 막아 둡니다. 그래서 마지막 선택 한 번은 사용자가 직접 해야 합니다.

## 소스에서 실행
```bash
pip install -r requirements.txt
python Koinfra.py [열 PDF 파일...]   # kpdf_*.py 모듈이 같은 폴더에 있어야 합니다
```
Python 3.11 또는 3.12, Windows 10/11에서 동작을 확인했습니다.

## 빌드
```bash
# 1) 실행 파일 (폴더형, 빠른 시작)
pip install pyinstaller
pyinstaller --noconfirm --distpath dist_installer --workpath build_installer KoinfraPDFEdit_installer.spec

# 2) 설치 파일 (Inno Setup 6)
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" KoinfraPDF.iss   # -> installer\KoinfraPDF_Setup_1.4.3.exe
```
`KoinfraPDFEdit.spec`은 실행 파일 하나로 만드는(onefile) 빌드용입니다.

## 테스트

```bash
python test/static_check.py .

python test/approval_test.py . out_appr t

python test/perf_cache_test.py . out_perf   # 문서·페이지 캐시, 썸네일 해상도, 렌더 캐시 보호
python test/thumb_grid_test.py . out_grid   # 썸네일 칸 너비별 1/2/3열 배치, 가운데 정렬, 선택·드래그·스크롤
python test/export_test.py . out_export   # 썸네일 선택(클릭/Ctrl/Shift/Ctrl+A), 우클릭 내보내기(PDF/엑셀/한글/이미지)
python test/convert_test.py . out_conv   # 변환: 엑셀 표·병합 셀, 한글(.hwpx 구조, 한컴 한글이 있으면 열기·.hwp 저장), 이미지 DPI, 스캔 PDF, 변환 창
```

## 변환 기능 안내
- **엑셀:** 표마다 시트 하나(`p1_표1`…)로 넣고 병합 셀을 유지합니다. 표 밖 글자나 표가 없는 페이지는 `p1_텍스트`(또는 `p2`) 시트에 줄 단위로 넣고, 넓게 띄어진 칸은 다른 셀로 나눕니다. 1,234 같은 숫자는 숫자로, 007 같은 코드는 글자로 둡니다.
- **한글:** `.hwpx`를 직접 만들어서 한글 프로그램이 없어도 됩니다(한글 2014 이상에서 열림). 글자는 문단, 표는 한글 표(테두리, 병합 셀, 머리글 행)로 옮기고, PDF 한 쪽이 한글 한 쪽에서 시작합니다. `.hwp`는 PC에 한컴 한글이 있을 때 한글로 저장합니다.
- **이미지:** 페이지마다 파일 하나(`이름_p001.png`)를 72~600 DPI로 저장합니다.
- **한계:** 글자와 표 중심이라 그림·도형·글꼴·정확한 위치는 옮기지 않습니다. 다단, 선 없는 표, 복잡한 서식은 줄 단위 글자로 들어갈 수 있습니다. 스캔 PDF(글자 정보 없음)는 엑셀·한글로 옮길 내용이 없어서 이미지 변환만 됩니다(OCR 미포함).

## 변경 사항
### 1.4.3
- 아이콘을 직접 그린 플랫 벡터 디자인으로 교체: 흰 문서 + 남색 외곽선, PDF 글자, 회사(KOINFRA) 로고 심볼(원래 색), 만년필
- 48px 이하는 로고와 펜 위주로 단순화, 24/16px은 선을 더 굵게 해 작은 크기에서도 또렷하게
- 프로그램·창·바로가기·PDF 파일 연결 아이콘, 설치 파일 아이콘, 설치 마법사 그림을 모두 새 디자인으로 변경

### 1.4.2
- 새 아이콘: 남색 PDF 문서 + 만년필 로고(바깥 둥근 테두리 없이 문서 모양만, 투명 배경)
- 프로그램(exe)·창·작업 표시줄·바로가기·PDF 파일 연결 아이콘, 설치 파일 아이콘, 설치 마법사 왼쪽 그림·오른쪽 위 작은 그림을 모두 새 로고로 교체(16~256px, 작은 크기는 선명하게 보정)
- 설치가 끝나면 Windows 아이콘 캐시를 새로 고침. 예전 아이콘이 계속 보이면 로그아웃 후 다시 로그인하거나 PC를 다시 시작하세요

### 1.4.1
- 썸네일에서 한 장 또는 여러 장(클릭, Ctrl+클릭, Shift+클릭, Ctrl+A)을 고른 뒤 오른쪽 클릭 → **내보내기** → PDF로(선택 페이지만 새 PDF) / 엑셀로 / 한글로 / 이미지로. 엑셀·한글·이미지는 변환 창이 선택 페이지 범위로 열림
- 선택되지 않은 썸네일을 오른쪽 클릭하면 그 한 장만 선택, 선택된 썸네일을 오른쪽 클릭하면 여러 장 선택 유지(오른쪽 버튼은 드래그·선택 해제를 하지 않음)
- 선택된 썸네일 표시를 더 진하게(파란 배경·테두리)
- 기존 우클릭 메뉴(잘라내기·복사·붙여넣기·회전·지우기)는 그대로

### 1.4
- 새 **변환** 탭(메뉴·툴바): 열린 PDF를 엑셀(.xlsx), 한글(.hwpx / .hwp), 이미지(PNG·JPG)로 저장. 화면에 보이는 그대로(합친 파일, 페이지 순서, 회전, 도장 포함) 변환하고, 다른 PDF 파일을 골라도 됨
- 페이지 범위(전체, 현재 페이지, 1-3,5), 저장 위치, 이미지 DPI 선택, 진행 표시와 취소, 끝나면 폴더 열기. 같은 이름 파일이 있으면 덮어쓰지 않고 `이름 (2)`로 저장
- 스캔 PDF(글자 정보 없음)는 미리 알려 주고 이미지 변환을 안내
- 기존 기능과 화면은 그대로

### 1.3.2
- 더 빨라짐(80쪽 PDF 기준): 열기 약 215 → 145ms, 20쪽 넘기기 약 810 → 530ms, 확대/축소 12번 약 270 → 145ms, 썸네일 스크롤 약 1.9 → 1.5초. 열어 둔 문서와 최근 페이지를 다시 쓰고, 파일은 메모리에서 읽어 잠그지 않음(탐색기에서 이름 바꾸기·덮어쓰기 가능, 바뀌면 자동으로 다시 읽음)
- 썸네일이 보이는 크기 그대로 그려져 선명함(넓은 칸에서 흐리던 문제 수정). 썸네일이 미리보기 캐시를 차지하지 않음
- 최대 메모리 사용 감소(약 142 → 130MB), 시작할 때 연결 등록이 이미 맞으면 레지스트리를 다시 쓰지 않고 탐색기 새로 고침도 하지 않음
- 설치 파일 크기 감소: 쓰지 않는 OpenGL·QtQuick·WebGL 구성요소와 AVIF/WebP 코덱 제외
- 쓰지 않는 코드 정리

### 1.3.1
- '연결 프로그램'으로 열면 아무것도 안 뜨고 아이콘이 기본 아이콘으로 보이던 문제 수정: 빌드·임시 폴더에서 실행한 사본이 PDF 연결을 자기 위치로 바꾸던 것을 막음(설치본이 있으면 항상 설치본으로 등록). 시작할 때 연결이 없는 파일을 가리키면 설치본으로 자동 복구
- 설치 시 아이콘 캐시를 새로 고쳐 '연결 프로그램'·기본 앱 화면에 Koinfra PDF 아이콘이 바로 보임, 예전 빌드가 남긴 App Paths 'Path' 값 정리

### 1.3
- 왼쪽 썸네일 칸을 넓히면 썸네일이 2열, 3열…로 바둑판처럼 배치됨(칸 너비에 맞춰 열 수 자동, 각 썸네일은 칸 가운데). 선택·드래그 순서 변경·페이지 번호·현재 페이지로 스크롤은 그대로

### 1.2
- 코드 정리: `Koinfra.py`(창·연결 프로그램) + `kpdf_core`(설정·페이지 모델) / `kpdf_graphics`(아이콘·결재란) / `kpdf_widgets`(썸네일·미리보기·서명/도장 창) / `kpdf_export`(PDF 저장·인쇄)로 나눔, 쓰지 않는 코드 제거
- 여러 장짜리 PDF를 빨리 엶: 페이지 크기를 문서 한 번 열 때 한꺼번에 읽음(80쪽 PDF 열기 약 650ms → 75ms)
- 시작이 빨라짐: pypdf·Pillow·인쇄 모듈은 저장·인쇄할 때 처음 불러옴(모듈 로딩 약 105ms → 60ms)
- 메모리 사용 감소: 미리보기 캐시를 장수(24)와 용량(192MB) 둘 다로 제한(80쪽 PDF 확대 후 약 475MB → 380MB)
- 도장·서명·결재란을 PDF에 넣을 때 임시 파일을 만들지 않음

### 1.1
- 썸네일 목록을 아래로 내리면 썸네일이 오른쪽으로 밀리던 문제 수정
- Ctrl+휠 확대·축소가 끊기던 문제 수정: 휠을 돌리는 동안에는 바로 확대해 보여 주고, 멈추면 선명하게 다시 그림(휠 한 칸당 약 110ms → 7ms). 고해상도 휠·터치패드는 한 칸 단위로 계산
- 툴바·메뉴의 확대/축소 버튼을 누르면 오류가 나던 문제 수정
- 확대한 상태에서 휠을 굴리면 페이지 안에서 먼저 스크롤하고, 끝에 닿으면 다음 페이지로 넘어감
- 저장(Ctrl+S) 뒤 페이지가 어긋나거나 다음 저장에서 회전·도장이 두 번 들어가던 문제 수정(저장한 파일을 다시 불러옴)
- 암호가 걸린 PDF를 저장하면 암호가 풀리던 문제 수정(같은 암호 유지)
- 저장 실패(권한·경로 오류 등) 때 프로그램이 꺼지지 않고, 원본 파일도 손상되지 않음
- 파일을 더블클릭해 열면 창 제목에 파일 이름이 나오고, 되돌리기로 문서가 사라지지 않음
